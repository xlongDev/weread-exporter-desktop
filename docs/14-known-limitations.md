# 14 - 已知限制

> 截至 v0.1.0（Phase 8 macOS 完成）。诚实清单 —— 每一条都真实存在。

## 平台与分发

1. **Windows 打包待验证**：工程已含 icon.ico 与资源脚本（prepare-runtime.sh 支持 x86_64），但 NSIS 安装包需在真实 Windows 机器上构建与验收，本次交付未覆盖（无 Windows 环境）。
2. **未签名/未公证**：macOS 包未经 Apple Developer 签名与公证，首次打开需右键 → 打开（或系统设置中放行）。签名公证需要开发者账号，属发布阶段事项。
3. **安装包体积**：.app 约 260MB / DMG 约 85MB —— 主要为捆绑的 Python 3.12 运行时 + Playwright 驱动（133MB，刚性成本）。
4. **浏览器依赖**：优先使用系统 Edge/Chrome；两者都没有时需要手动 `playwright install chromium`（约 200MB 下载），未做到全自动。

## 功能边界（设计决定，非缺陷）

5. **无 TXT 格式**：原引擎不支持，不伪装支持。
6. **无"暂停"按钮**：引擎无安全暂停点；用"取消 + 继续导出"达到同样效果（章节级断点保真）。
7. **抓取速度固定**：温和防风控（8~20s 随机翻页 + 长停顿），不可调快；整本导出 1~3 小时。
8. **同一时刻一个抓取任务**：浏览器 profile 单实例约束；多格式/多书任务自动排队。
9. **侧边栏不折叠**：窗口最小宽度 1080px 已保证布局完整；折叠图标栏未实现。

## 技术观察

10. **微信读书页面结构变化**会导致 Canvas 捕获失效 —— 外部依赖风险，只能跟随适配（Phase 0 风险 #1）。
11. **裸 `cargo build`**（不经 tauri CLI）的调试二进制页面不加载（tauri:// 资产）—— 官方路径 `tauri dev` / `tauri build` 不受影响。
12. **真实扫码登录的端到端验收**依赖人工扫码：自动化覆盖了登录检测（真实 Cookie 验证 logged_in=true）与全部协议链路；扫码 UI 流程待用户日常使用中确认。
13. **自动更新未实现**：应用内无更新机制（设置中无假开关）；需手动更新。
