# 15 - 用户手册

## WeRead Exporter Desktop 使用说明

### 这是什么

一款桌面应用，把你在微信读书中**有权阅读**的书籍导出为三种格式，保存在你自己的电脑上：

| 格式 | 适合 | 说明 |
| --- | --- | --- |
| 精排 PDF | iPad 批注、打印 | 含封面、可点击目录、PDF 书签大纲与页码 |
| EPUB | Apple Books / Kindle | 双字体排版，内嵌目录与原书插图 |
| Markdown | Obsidian / Notion | 生成「纯笔记版」与「HTML 排版版」两个文件 |

### 系统要求

- macOS 12 及以上（Apple Silicon / Intel），或 Windows 10/11 x64
- 本机装有 Google Chrome 或 Microsoft Edge（用于微信扫码登录与书籍渲染；没有也可以，见下方"常见问题"）
- 无需安装 Python 或任何开发工具 —— 一切已内置

### 第一次使用

1. 打开应用，首页会显示"微信读书账号：未登录"。
2. 点击 **登录微信读书**，会弹出一个浏览器窗口。
3. 用微信扫描窗口中的二维码（3 分钟内完成）。
4. 登录成功后，点击 **导出书籍**。

### 导出一本书

1. **选书**：在微信读书网页版打开你想导出的书，复制浏览器地址栏链接，粘贴进输入框，点击「获取书籍」。确认封面、书名、作者无误后点击「导入书籍」。
2. **格式**：勾选一种或多种格式（每种格式生成一个任务）。
3. **选项**：选择保存位置（默认「文稿/WeRead-Exports」）。
4. **确认**：核对信息后点击「创建导出任务」。

### 等待导出完成

- 在 **任务中心** 可以看到实时进度：当前章节、已完成章节数、已抓取页数与字数、已耗时。
- 导出速度是固定的温和模式（每翻一页随机等待 8~20 秒），**整本书通常需要 1~3 小时**，请耐心等待并保持网络连接。这是为了保护你的账号安全，不可调快。
- 完成后点击任务上的「文件夹」可以直接打开导出目录。
- 需要中途停止？点「取消」。已抓取的章节不会丢失 —— 之后在任务详情里点「继续导出」，会从断点处接着抓。

### 书库

导出完成的文件会出现在 **书库** 页：封面墙或列表两种视图，支持按书名/作者搜索、按格式筛选。可以打开文件、在访达中定位、删除记录或连文件一起删除（删除有确认，不会误删）。

### 设置

- **主题**：浅色 / 深色 / 跟随系统。
- **默认导出目录**：每次导出的默认保存位置。
- **退出登录**：清除本机保存的微信读书登录态。
- 数据（任务记录、设置）全部保存在本机，不会上传到任何服务器。

### 常见问题

**Q：点登录没有反应 / 提示浏览器启动失败？**
应用会优先使用系统已装的 Edge 或 Chrome。如果两者都没有，请在终端执行一次 `playwright install chromium`（可在应用数据目录的 runtime 下执行），或先安装 Chrome。

**Q：提示"浏览器配置目录被占用"？**
上一次导出的浏览器窗口还在后台运行。完全退出它再试。

**Q：扫码后一直没反应？**
登录状态最长等待 300 秒，超时后重新点「登录微信读书」再扫一次。

**Q：导出的 PDF 在哪里？**
默认在「文稿/WeRead-Exports」，也可以在导出向导第三步自行指定。

**Q：任务失败了怎么办？**
打开任务详情查看失败原因；「重试」或「继续导出」会复用已抓取的内容，不会从头再来。

### 使用边界（请务必阅读）

- 本工具仅用于个人学习与备份你**有权阅读**的内容；导出的文件请勿传播或商用。
- 微信读书页面改版可能导致某次导出失败 —— 这属于外部依赖变化，可反馈 issue 等待适配。
- 请合理安排导出频率，温和模式是刻意的保护设计。
