# 15 - 用户手册

## WeRead Exporter Desktop 使用说明

### 这是什么

一款桌面应用，把你在微信读书中**有权阅读**的书籍导出为三种格式，保存在你自己的电脑上：

| 格式 | 适合 | 说明 |
| --- | --- | --- |
| 精排 PDF | iPad 批注、打印 | 含封面、可点击目录、PDF 书签大纲与页码 |
| EPUB | Apple Books / Kindle | 双字体排版，含封面页、目录与原书插图（书架内显示封面缩略图） |
| Markdown | Obsidian / Notion | 生成「纯笔记版」与「HTML 排版版」两个文件 |

### 系统要求

- macOS 12 及以上（Apple Silicon / Intel），或 Windows 10/11 x64
- 本机装有 Google Chrome 或 Microsoft Edge（用于微信扫码登录与书籍渲染；没有也可以，见下方"常见问题"）
- 无需安装 Python 或任何开发工具 —— 一切已内置

### 下载安装

从 [Releases 页](https://github.com/xlongDev/weread-exporter-desktop/releases) 下载对应平台的安装包；或用一键安装脚本（下载 + 校验和 + 安装一步完成）：

    # macOS（推荐：命令行下载无隔离标记，不会出现「已损坏」提示）
    curl -fsSL https://raw.githubusercontent.com/xlongDev/weread-exporter-desktop/main/scripts/install-macos.sh | bash

    # Windows（PowerShell）
    irm https://raw.githubusercontent.com/xlongDev/weread-exporter-desktop/main/scripts/install-windows.ps1 | iex

应用内置「检查更新」：设置 → 关于 → 检查更新，会对比 GitHub 最新版本并给出上述安装命令。

### 第一次使用

1. 打开应用，首页会显示"微信读书账号：未登录"。
2. 点击 **登录微信读书**，会弹出一个浏览器窗口。
3. 用微信扫描窗口中的二维码（3 分钟内完成）。
4. 登录成功后，点击 **导出书籍**。

### 导出一本书（三步）

1. 复制微信读书网页版的书籍链接，粘贴进「导出书籍」页的输入框，点「获取书籍」。
2. 确认封面与书名，默认导出全部三种格式到默认目录（都可改：点格式圆片取消、点「更改…」换目录）。
3. 点「开始导出」—— 完成。之后到任务中心看进度。

### 从书架导入（免粘贴链接）

1. 点输入框右侧的 **从书架导入**，应用会自动拉取你的微信读书书架（首次需启动浏览器，约数秒）。
2. 在封面墙中搜索/勾选要导出的书（可多选），点 **导出所选（N）**。
3. 之后与批量粘贴同一流程：逐本获取信息并入队，逐条列出成功/失败原因。注意多本导入是**逐本排队**的，不是秒级全量。

### 导出划线与想法（笔记）

导出格式里多了一种 **笔记**：拉取该书你在微信读书里的划线（按章节分组）与想法，生成一个 `{书名}_划线与想法.md` 文件，**无需逐页抓取、秒级完成**。该书没有划线也没有想法时会明确提示「无可导出的笔记」。

### 排版选项（设置 → 导出）

- **正文字号**：小 12 / 标准 / 大 15 / 特大 17，对 PDF 与 EPUB 正文生效（适合 e-ink / Kindle 阅读）。
- **PDF 页边距**：窄 / 标准 / 宽。
- 「标准」即内置排版；改动只影响之后新创建的导出任务。

### 等待导出完成

- 在 **任务中心** 可以看到实时进度：当前章节、已完成章节数、已抓取页数与字数、已耗时。
- 导出速度是固定的温和模式（每翻一页随机等待 8~20 秒），**整本书通常需要 1~3 小时**，请耐心等待并保持网络连接。这是为了保护你的账号安全，不可调快。
- 完成后点击任务上的「文件夹」可以直接打开导出目录。
- 需要中途停止？点「取消」。已抓取的章节不会丢失 —— 之后在任务详情里点「继续导出」，会从断点处接着抓。

### 书库

导出完成的文件会出现在 **书库** 页：封面墙或列表两种视图，支持按书名/作者搜索、按格式筛选。可以打开文件、在访达中定位、删除记录或连文件一起删除（删除有确认，不会误删）。

### 设置

- **主题**：浅色 / 深色 / 跟随系统。
- **默认导出目录**：每次导出的默认保存位置。
- **检查更新**：优先应用内更新（发现新版本可直接「下载并安装」，装完重启生效）；发布页尚未提供更新包时自动回退为版本比对 + 发布页链接和一键安装命令。
- **正文字号 / PDF 页边距**：见上「排版选项」。
- **复制诊断信息**：问题反馈时附上（含版本、近期失败任务与脱敏日志），可加快定位。
- **退出登录**：清除本机保存的微信读书登录态。
- 数据（任务记录、设置）全部保存在本机，不会上传到任何服务器。

### 登录失效怎么办

导出过程中如果微信读书登录态过期，任务会明确提示「登录已失效」并停在断点处（不会误标为完成）。重新扫码登录后，在任务详情点「继续导出」，会从断点接着抓，已抓内容不丢。

### 常见问题

**Q：macOS 首次打开提示「已损坏，无法打开」？**

这是 macOS 对未签名应用的 Gatekeeper 拦截（浏览器下载的 DMG 带隔离标记），两种解决办法：

**方式一（推荐）一键安装脚本** —— 终端执行，命令行下载安装，**完全不会出现「已损坏」提示**：

    curl -fsSL https://raw.githubusercontent.com/xlongDev/weread-exporter-desktop/main/scripts/install-macos.sh | bash

（下载慢可加加速代理：`WEREAD_MIRROR_PREFIX=https://<GitHub加速代理> curl -fsSL … | bash`）

**方式二 手动清除隔离标记** —— 先把应用拖入「应用程序」，终端执行：

    xattr -dr com.apple.quarantine "/Applications/WeRead Exporter.app"

（若提示权限不足，命令前加 `sudo `。）

注：新版 macOS 已取消「右键 → 打开」的绕过方式，请用上述两种方法。

**Q：点登录没有反应 / 提示浏览器启动失败？**
应用会优先使用系统已装的 Edge 或 Chrome。如果两者都没有，可在终端执行一次（macOS）：

    "$HOME/Library/Application Support/weread-exporter/runtime/bin/python3" -m playwright install chromium

或直接安装 Chrome / Edge 后重试。

**Q：提示"浏览器配置目录被占用"？**
上一次导出的浏览器窗口还在后台运行。完全退出它再试。

**Q：扫码后一直没反应？**
登录状态最长等待 300 秒，超时后重新点「登录微信读书」再扫一次。

**Q：导出的 PDF 在哪里？**
默认在「文稿/WeRead-Exports」，也可以在导出向导第三步自行指定。

**Q：任务失败了怎么办？**
打开任务详情查看失败原因；「重试」或「继续导出」会复用已抓取的内容，不会从头再来。

### 使用边界（请务必阅读）

- 本工具仅用于个人学习与备份你**有权阅读**的内容；导出的文件请勿传播或商用。
- 微信读书页面改版可能导致某次导出失败 —— 这属于外部依赖变化，可反馈 issue 等待适配。
- 请合理安排导出频率，温和模式是刻意的保护设计。
