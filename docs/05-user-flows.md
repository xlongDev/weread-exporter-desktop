# 05 - 用户流程

## F1 首次启动
启动 → 总览页显示"未登录"引导卡（唯一大块）→ 点击"登录微信读书" → 弹出可见浏览器窗口 → 用户微信扫码（300s 窗口）→ 引擎上报 auth.success → 总览登录卡变为"已登录" → 引导卡片替换为"导出书籍"主行动。
异常：扫码超时 → 提示重试；浏览器启动失败 → 展示原因（未安装 Chrome/Edge → 引导安装或下载 Chromium）。

## F2 登录态检查（每次启动）
启动 → Rust 向引擎发起会话检查（启动浏览器上下文读取 Cookie）→ auth.status 事件 → UI 更新。
已过期 → 总览登录卡显示"会话已过期"，提供重新登录与清除会话。

## F3 导入书籍
导出向导第 1 步 → 粘贴链接/ID → 前端正则即时校验（`extract_book_id` 同规则）→ 通过后 Rust 调引擎 `book.info` → 返回元数据（书名/作者/简介/封面 URL）→ 书籍卡片渲染封面（本地缓存）。
失败分支：链接无效（即时提示格式）· 未登录（引导 F1）· 无权访问/书籍不存在（引擎返回明确错误码）。

## F4 导出向导（4 步）
选书完成 → 选格式（PDF/EPUB/MD 多选）→ 配置（目录选择器 = 原生文件夹对话框、命名、覆盖策略）→ 确认页汇总 → "创建导出任务" → 任务写入 SQLite（状态 waiting）→ Rust 排队执行 → 跳转任务中心（或留在总览看进度）。
耗时提示：确认页按引擎真实页速（8~20s/页）与估算页数给出区间 + "期间请保持网络连接"。

## F5 任务执行与监控
任务启动 → 引擎事件流（task.started / task.progress）→ 任务行实时更新（当前章节、页 n、字数、已耗时）→ 章节落盘时进度条推进。
完成 → task.completed → 书库新增记录（文件路径、大小、格式）→ 通知（按系统设置）→ "打开文件夹"入口。
失败 → task.failed（含 userMessage + 技术详情折叠）→ 可重试 / 继续导出。

## F6 取消与继续
任务行"取消" → Rust 发送 cancel 指令 → 引擎在下一翻页边界优雅停止（保存状态、关闭浏览器）→ task.cancelled。
"继续导出" → 校验任务记录 → 引擎复用 output/{book}_v2 已落盘数据，从上次章节后继续 → 新任务记录关联原任务。

## F7 书库管理
搜索/筛选 → 打开文件（系统默认程序）/ 定位文件夹（Finder/Explorer）→ 删除：先确认对话框（指明文件名）→ 仅删记录 or 连文件一起删（两个明确选项）→ 文件缺失行提示 + "清理无效记录"。

## F8 应用关闭保护
有执行中任务时点关闭 → 确认对话框（"导出正在进行，关闭将中断任务（已抓取内容不会丢失，可稍后继续）"）→ 确认后优雅取消任务再退出。

## F9 引擎异常恢复
引擎进程退出（崩溃/被杀）→ Rust 检测 → 任务标记 failed（原因：引擎异常退出）→ raw 落盘数据完好 → 提供"继续导出"（自动从断点恢复）。
