# 04 - 产品需求文档（PRD）

## 1. 定位

WeRead Exporter Desktop：面向普通用户的微信读书电子书导出与本地书库管理桌面应用。用户不理解 Python / Playwright / 终端；打开应用 → 扫码 → 粘贴链接 → 等待真实进度 → 在书库中拿到 EPUB / PDF / Markdown。

## 2. 目标用户

1. 想备份自己有权阅读的微信读书书籍的普通读者（主要）。
2. 想把书导出为 EPUB/PDF 在其他设备阅读的用户。
3. 想把书归档进 Obsidian/Notion 知识库的用户（Markdown）。
4. macOS 用户先行，Windows 用户第二批。

## 3. 信息架构（5 个一级页面）

```text
┌────────────┬──────────────────────────────────┐
│ Sidebar    │  Content                         │
│  总览       │  Dashboard / 向导 / 任务 / 书库 / 设置 │
│  导出书籍    │                                  │
│  任务中心   │                                  │
│  书库       │                                  │
│  设置       │                                  │
└────────────┴──────────────────────────────────┘
```

## 4. 页面需求

### 4.1 总览 Dashboard
一句话回答："现在能不能导？上次导了什么？正在跑什么？"
- 登录状态卡（已登录/未登录/已过期 + 登录按钮）。
- 正在进行的任务（大块：真实进度条、当前章节、页数、已耗时；无任务时显示引导）。
- 最近导出（书库最近 4 条，封面 + 书名 + 时间）。
- 统计（已导出书籍数 / 任务数 / 成功数）——纯文字型 KPI，不做卡片堆砌。
- 主行动按钮："导出书籍"。

### 4.2 导出书籍（向导）
4 步：选书 → 选格式 → 选项 → 确认。
1. **选书**：粘贴 URL 或书籍 ID → 实时校验 → 显示书籍卡片（封面/书名/作者/简介）+ 可访问性检查结果。失败给具体原因（链接无效 / 未登录 / 无权访问）。
2. **选格式**：仅展示真实支持的三种 —— PDF（精排，适合 iPad/打印）、EPUB（Apple Books/Kindle）、Markdown（Obsidian/Notion）。多选。每种含说明与限制。
3. **选项**：输出目录（默认 ~/Documents/WeRead-Exports）、文件命名（书名/书名+作者）、封面开关、覆盖策略。不支持的选项一律不展示（不出现灰色假开关）。
4. **确认**：书籍信息 + 格式 + 输出路径 + 预计耗时提示（按真实页速估算区间，注明"取决于书籍长度与网络"）。提交 → 创建真实任务。

### 4.3 任务中心
- 状态分列/筛选：等待 / 执行中 / 已完成 / 已取消 / 失败。
- 任务行：封面、书名、格式徽章、状态徽章、真实进度（章节 n/m + 百分比）、已耗时、输出路径。
- 操作：详情、取消（执行中）、继续导出（已完成部分章节的任务，复用引擎断点数据）、重试（失败）、打开文件夹、清理历史。
- 详情抽屉：阶段时间线、章节级进度、错误详情（技术信息折叠）、日志入口。
- 约束：同一时刻最多 1 个抓取任务（浏览器 profile 单实例）；取消 = 优雅停止，已落盘章节保留。

### 4.4 书库
- 封面墙（网格）与列表两种视图；搜索（书名/作者）、格式筛选、时间排序。
- 每本书：封面、书名、作者、格式徽章（多格式）、大小、时间；操作：打开文件、定位文件夹、重新导出、删除记录、删除文件（删除必须确认，文件与记录分离确认）。
- 文件丢失（被移动/删除）时行内明确提示"文件缺失"，不假装可用。

### 4.5 设置
- 通用：默认导出目录、默认格式、语言（zh-CN 先行）、主题（浅色/深色/跟随系统）。
- 导出：文件命名规则、覆盖策略、封面下载开关。
- 数据与隐私：数据目录位置展示、清除缓存、清除登录会话、导出诊断报告（脱敏）。
- 关于：版本、引擎版本、开源许可（MIT + 第三方）、项目地址、更新日志。

## 5. 功能边界（诚实性承诺）

| 项 | 结论 |
| --- | --- |
| TXT 导出 | 不提供（引擎无此格式，不伪装） |
| 任务暂停 | 不提供"暂停"按钮；提供"取消"，取消后可从断点继续（引擎真实能力） |
| 扫码方式 | 弹出系统浏览器窗口扫码（Playwright 可见窗口），不做 WebView 内嵌 |
| 导出速度 | 不可调节（温和防风控为默认且固定），UI 明示耗时预期 |
| 自动更新 | 本期不承诺，设置中不出现假开关 |

## 6. 验收口径

- 全部功能真实可用，无占位页面、无假数据、无无效按钮。
- 格式支持 = 原引擎真实能力（PDF/EPUB/MD 双版本），有真实产物。
- 任务进度 = 引擎上报的真实页/章数据，非定时器伪造。
- macOS 安装包可独立安装运行（先），Windows 其次。
