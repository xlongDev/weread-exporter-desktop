# 01 - 已有功能清单与复用分类（Phase 0）

> 分类口径：✅可直接复用 · 🔧需封装 · ♻️需小幅重构 · ➕需新增 · ⛔无法可靠实现

## 引擎能力（Python 现状）

| 能力 | 分类 | 说明 |
| --- | --- | --- |
| 链接/ID 解析 `extract_book_id` | ✅ | 纯函数，含 6 处真实格式分支，直接复用 |
| 可见浏览器登录 + Cookie 校验 | 🔧 | 逻辑复用；桌面端需管理 profile 位置、窗口生命周期与登录态上报 |
| 浏览器多候选回退（Edge/Chrome/Chromium） | ✅ | 原样保留 |
| Canvas 字符捕获 / 双栏翻页 / 分页切栏 | ✅ | 核心资产，禁止重写 |
| 章节识别（目录反推 + 粘连剥离） | ✅ | 核心资产 |
| 章节实时落盘 + 逐页 raw 落盘 + 状态自愈重构 | ✅ | 桌面端"断点续导"的地基，直接复用 |
| 插图捕获与统一补全下载 | ✅ | 原样保留 |
| 元数据抓取 + 封面下载 | 🔧 | 复用；需把结果以事件形式上报 UI |
| Markdown 双版本生成 | 🔧 | 复用；输出目录需参数化 |
| EPUB 生成（EbookLib） | 🔧 | 复用；同上 |
| PDF 精排生成（Playwright headless） | 🔧 | 复用；同上 |
| 温和抓取（随机延迟 + 长停顿） | ✅ | 保留为默认策略 |
| 进度输出 | ♻️ | 现为 `print()` 人类可读文本；需增加结构化事件回调（默认关闭时行为不变） |
| 输出目录 | ♻️ | 硬编码 `BASE/output`；需支持注入 `output_dir`（默认值不变） |
| TXT 导出 | ⛔ | 原项目无此格式，桌面版不承诺该格式（防"伪装支持"） |
| 任务暂停 | ⛔ | 引擎无安全暂停点；桌面版提供"取消"，取消后凭章节级落盘自然支持"继续导出" |
| 扫码页内嵌 Tauri WebView | ⛔ | 微信读书登录需独立浏览器上下文，必须弹出可见浏览器窗口 |

## 桌面端能力（全部 ➕ 新增）

Tauri 2 工程、React + TS 前端、设计系统、SQLite 数据层（含迁移）、JSON 协议进程管理、任务中心、书库、设置中心、诊断日志、跨平台打包 —— 均为新增，见 `03-migration-plan.md`。

## 结论

原项目的抓取与导出核心（约 1300 行）质量可用、行为已被真实产物验证，**全部保留复用**；桌面化所需的重构仅集中在两点：**进度事件化** 与 **输出目录参数化**，且均以"默认参数保持原行为"的方式进行，CLI 用法不变。
